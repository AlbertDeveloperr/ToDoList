# ToDo List

Простое консольное приложение на Python для управления списком задач.

## Возможности
- Добавление новых задач
- Просмотр списка задач
- Удаление задач
- Отметка выполненных задач

## Установка и запуск
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/AlbertDeveloperr/ToDoList.git


2. - Перейдите в папку проекта:
cd ToDoList

3. - Запустите приложение:
python todo.py


Структура проекта- todo.py — основной файл приложения
- README.md — описание проекта
- .gitignore — исключённые файлы и папки


Пример использования
1. Добавить задачу
2. Просмотреть задачи
3. Удалить задачу
4. Отметить задачу как выполненную
